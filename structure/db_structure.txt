Purchase backend notes
- Create purchase can use existing Inventory product_id
- Create purchase can also register a new Inventory item using barcode as the stable lookup key
- Purchase return deducts stock and marks purchase status as returned
- Purchase list supports filters by supplier, status, product, user, and date range
